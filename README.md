# github-issue-backup
small Python tool to download and view repositories

- Run archive_github_issues.py to archive the repo
- Run display_script.py to create a html viewer inside the newly created repository

Vibecoded using Claude for download and Qwen for html viewer.
The intent was to create a small and simple script to be able to save a repository before losing it. I intended it to use a minimal amount of imports, but get the job done as quickly and dirtily as possible.
